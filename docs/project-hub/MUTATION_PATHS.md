Rule applied everywhere: **signals are projections, not protection.** Critical gates (approval creation, claim, run start, controlled runner actions, merge) re-read the native issue, project, membership and approval state inside the request/transaction, so a delayed or missing event can never make a stale approval valid (PF06, MIGRATION §3).
