# Dokumenten-Diff

`PRD-v0.1-v0.2.diff` ist der vollständige Unified Diff zwischen dem bereitgestellten PRD 0.1 und dem aktualisierten PRD 0.2. Er ist kein Patch für den Plane-Quellcode. `PLANE_DELTA.md` beschreibt die Auswirkungen einschließlich der aktualisierten Begleitunterlagen.

Die Greenfield-Fassung und ihre alten JSON-Payloads sind nicht mehr operative Implementierungsvorgaben. Die bisherigen Downloads bleiben unverändert; dieses Paket ist die neue maßgebliche Fassung für den Plane-Ansatz.

`PRD-v0.1.md` ist die unveränderte Vergleichsquelle und ausdrücklich nicht die aktuelle Implementierungsvorgabe. Der Validator rekonstruiert den Unified Diff aus beiden Dokumenten.
